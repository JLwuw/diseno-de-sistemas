ReservaU es una plataforma de reservas de espacios universitarios. La información obtenida
en esos role plays forma parte de la especificación de este PSet.

El primer stakeholder explicó cómo funciona el proceso de reservas.

Los estudiantes pueden utilizar ReservaU para reservar canchas deportivas disponibles en el
campus para actividades individuales o informales.

También hay capitanes de equipos oficiales. Un capitán puede realizar las mismas acciones
que un estudiante, pero existe una regla: los equipos oficiales tienen prioridad para reservar
antes de las 6:00 p. m.

El segundo stakeholder explicó el proceso de cancelación y algunas responsabilidades
administrativas.

Un estudiante puede cancelar su propia reserva.

Si la cancelación ocurre con suficiente anticipación, se procesa como una cancelación normal.
Sin embargo, existe una regla de negocio:

Si un estudiante cancela cuando faltan menos de 2 horas para el inicio de la
reserva, la acción debe registrarse como no-show en lugar de una cancelación
regular.

El administrador del complejo deportivo también participa en ReservaU. Es responsable de:

* Gestionar las canchas disponibles
* Intervenir en conflictos relacionados con las reservas.

La regla de las 2 horas debe aplicarse por el sistema. El usuario no decide si una acción se
registra como cancelación o como no-show.
